# My Library
- This project was done to complete the JavaScript course on The Odin Project.
- Built using vanilla HTML, CSS, and JavaScript.
- Book data is stored in a JavaScript array and rendered dynamically to the DOM.
## Learned
- How to use constructor functions to create objects with a shared structure.
- How to generate unique IDs using `crypto.randomUUID()`.
- How to separate data (the book array) from the DOM (what's displayed on the page).
- How to dynamically create and render HTML elements using JavaScript.
- How to link DOM elements back to their corresponding objects.
- How event delegation works, and why it's needed when elements are created/destroyed dynamically.
- How to add prototype methods to a constructor function.
- The difference between `method="dialog"` forms and `event.preventDefault()` for handling form submission manually.
- How to use CSS Grid to build a responsive card layout.
